# Recurring terminology update

User-facing wording was updated from "rebill/rebilling" to clearer recurring-payment terminology. Internal API routes, DB fields, function names, and payment-origin code values remain unchanged for compatibility.

Key UI labels:
- Rebill card payment → Recurring card payment
- Rebill payment method → Recurring payment method
- Upcoming rebills → Upcoming recurring payments
- Rebill interval → Billing interval
- Rebilling schedules → Recurring schedules
